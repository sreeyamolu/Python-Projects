# Legends of the Forgotten Realm

## Project Description

Legends of the Forgotten Realm is a Python-based Command Line Interface (CLI) Role-Playing Game (RPG). Players can choose from four character classes, fight enemies and powerful bosses, collect rewards, purchase weapons and armor, use potions, explore different locations, and save their game progress.

## Features

- Four character classes: Warrior, Mage, Archer, and Assassin
- Character statistics and level-up system
- Battle system with attacks, special skills, critical hits, and defense
- 25 different normal enemies and 10 powerful bosses
- Weapon and armor shop
- Multiple types of potions
- Inventory and loot collection system
- World map with unlockable locations
- Gold and experience (EXP) reward system
- Save and Continue Game functionality

## Technologies Used

- Python 3.x
- JSON (for saving game progress)

## Project Structure

- `main.py` – Main game logic and menu
- `player.py` – Player details, character classes, and level-up system
- `enemy.py` – Enemy and boss details
- `battle.py` – Battle mechanics and combat system
- `shop.py` – Weapon, armor, and potion shop
- `save_load.py` – Save and load game progress
- `potions.py` – Potion details and inventory
- `weapons.py` – Weapon and armor details
- `world_map.py` – Game locations and unlocking system
- `savegame.json` – Saved game data

## How to Run

1. Install Python 3.x.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python main.py
```

## How to Play

1. Select New Game to start a new adventure.
2. Enter your player name.
3. Choose a character class.
4. Select a location and start battles.
5. Defeat enemies and bosses to earn EXP and gold.
6. Purchase and equip weapons and armor.
7. Use potions to restore health and mana or gain special effects.
8. Explore different locations as you progress.
9. Save your progress and use Continue Game to resume your adventure.
