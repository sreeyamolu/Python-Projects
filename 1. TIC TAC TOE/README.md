# Tic-Tac-Toe Game

## Project Description
Tic-Tac-Toe is a simple two-player game developed using Python 3. The game runs in the Command Line Interface (CLI).

## Objective
The objective of the game is to get three matching symbols in a row, column, or diagonal.

## Game Rules
- Player 1 uses X.
- Player 2 uses O.
- Players take turns entering a position from 1 to 9.
- A player wins by placing three matching symbols in a row, column, or diagonal.
- If all nine cells are filled and nobody wins, the game ends in a draw.

## Features
- 3x3 game board
- Two-player gameplay
- Player turn handling
- Input validation
- Occupied cell validation
- Win detection
- Draw detection
- Play again option

## Technologies Used
- Python 3
- Visual Studio Code

## Requirements
Python 3.x must be installed on the computer.

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python tic_tac_toe.py
```
